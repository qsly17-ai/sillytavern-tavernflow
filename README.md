# 清酌 TavernFlow 0.5.1

面向 **SillyTavern 1.19.0 正式版（7e8663cd9）** 的独立性能扩展，含浏览器扩展和配套服务端插件。替代鸡尾酒、鸡尾酒+、柏宝箱及旧线性补丁的约定性能职责；保留 MVU、酒馆助手、提示词模板、小白X和数据库。不是旧工具箱全部附加功能的复刻。

## 0.5.1 长聊天与大存档

- 最新五楼退出历史绘制观察的工作队列。同批历史更新按楼层合并，仍立即显示编辑、选择和互动内容。
- 差量比较少走一遍已比较的历史，哈希、冲突保护、协议和宿主落盘不变。
- 小白X 3.2.8/3.2.9 恢复双空快速路径；未知实现继续调用原生。
- 对照与范围见 [0.5.1 验收](reports/acceptance-0.5.1.md)，继续开发见 [维护手册](MAINTENANCE.md)。

## 0.5.0 手机与长聊天（历史）

- 开屏设置和聊天响应在同一次读取中只解析一次；设置内层也复用校验结果。异常群聊响应先恢复读取，不当作新群聊。
- 大设置或聊天保存保留原生同步快照，符合条件时省去前台的重复编码与 gzip。后台完整快照同时受数量和总大小限制，淘汰后保留冲突保护。
- 辅助生成：酒馆助手 4.12.2 明确只取最近几楼时，跳过可证明不会触发额外行为的旧楼转换；会改变量的规则等继续全量执行。合并同一轮内重复请求的提示词面板刷新。不会改变 MVU 配置的历史楼数、模型或注入内容。
- 适配酒馆助手 4.12.1/4.12.2、小白X 3.2.5/3.2.6/3.2.7。模块状态显示是否接管、因何降级。需要诊断时，在清酌面板展开「记录一次手机卡顿」；两分钟内的统计只留在该页，可手动结束。浏览器不支持长任务计时会明确提示。
- 测量方式、可复现对照和未覆盖场景见 [0.5.0 验收](reports/acceptance-0.5.0.md)。

## 0.4.1 存档与弱网保护

- **保存保护**：设置和聊天以页面实际打开的版本为准。后台查阅同一份文件不会改变版本，慢读取也不会挡住其他资源保存。发现冲突或保存结果不明时，先保留未保存的修改，再刷新读取。
- **兼容原生聊天**：与原生保存使用同一套聊天文件名规则。合法的角色名如“侦探: 林”也能正常保存。原生完整性提醒允许确认覆盖，但确认期间如果文件已经更新，仍会拒绝保存。被删除的角色按原生 404 处理。
- **减少一次大下载**：Quick Reply 仅读取快捷回复预设。专用接口不可用时，自动回到原生完整设置请求。

## 延续的弱网优化

- **弱网读取恢复**：在原生启动之前接入明确的同源 JSON 读取。长时间没有数据、网关错误、响应截断时，完整重试一次；连续失败显示“重试读取”。成功后仍由原生酒馆和业务插件处理完整数据，不伪造空聊天、不重试保存。
- **启动传输减负**：符合协商与大小预算的完整设置响应，采用有界异步 Brotli 压缩；不缓存私人响应，解压后内容不变。
- **更早接管差量保存**：扩展加载后即准备同一个 Worker 保存会话，减少业务插件启动途中重复全量上传；APP_READY 后继续使用该会话。
- **保留上一版能力**：助手接管重前端源码前减负、历史文字按需绘制、Token 合批及常用操作优化继续保留。MVU、酒馆助手、提示词模板、小白X、数据库和私人预设仍使用原有实现。

首屏插件预取 `startupPreload` 为**默认关闭的实验项**。它只提前下载后续插件入口，业务模块仍按原生顺序执行；当前尚无稳定提速证据。清酌继续等待原生初始化，不以空角色列表、旧响应或提前撤遮罩制造更快就绪。轻量拖影也默认关闭。

网络恢复覆盖原生设置、角色、聊天、世界书和背景列表的明确 JSON 读取。后台查询设置或历史聊天沿用调用方的行为。业务插件自己创建的其他异步等待仍可能阻塞。

## 延续的优化

- **后台差量保存**：设置、单聊、群聊的解析、差量、哈希及提交交给 Worker。同资源排队，无变化也真实核验；小改不再多构造一个全量包。保留未知字段、swipe 和业务数据。
- **长聊天绘制减负**：保留全部 DOM，远离屏幕的历史纯文字按需绘制。最近5楼、iframe整楼、交互HTML、编辑与选区保持实时，不拆助手页面。
- **常用操作响应**：大选项列表精确查询快路、抽屉即时展开、预设启停立即反映原生权威值；原生计算与保存继续执行。
- **命令与计数**：指纹守卫的线性命令扫描、精确正则起点、小白X双空集合清理跳过；合并短时间并发Token请求，调用原生计数，不按字数猜Token。
- **服务器新鲜读取**：匹配已核验源码时，将 settings/get 的同步文件读取换为并发上限8的异步读取。每次读取新数据，完整返回原生内容；不缓存旧响应、不改核心文件。源码指纹不符就保留原生路径。

“轻量拖影”的历史合成测试减少了累计任务耗时，但没有帧率改善证据。

原生 JSON.stringify、未接管路径的请求压缩和服务端完整文件落盘仍存在；首次未知基线可能额外下载完整数据。面板“减少上传”只统计本模块提交的请求体，不含下载、HTTP头、整站流量。没有承诺所有大卡、手机耗电或每次首屏都改善。

## 使用与版本确认

打开酒馆 → 顶部扩展设置 → **清酌**，确认 0.5.1 和模块状态。更新后先复制未保存输入，关闭所有旧酒馆标签页，再重新打开。网络不畅时重试提示会等待完整读取；若读取期间聊天已切换，提示保存草稿后重新加载，避免迟到响应进入其他聊天。

上一版本验收见 [0.5.0](reports/acceptance-0.5.0.md) 和 [0.4.1](reports/acceptance-0.4.1.md)，0.4.0 的历史测量见 `reports/acceptance-0.4.md`。模拟弱网与窄屏浏览器不等于手机真机高峰验收。

私人预设的循环任务由小白X管理，需要预设本身携带完整定义。清酌不提供、补装或替换这些任务；验收报告中的相关修复只记录该次获授权的独立维护，不作为通用安装步骤。

面板总开关只暂停**当前页前端**。服务端启动读取随插件加载，完整卸载需处理前后端并重启。旧组合的楼层目录、预设分组等工具入口不属于本品；暂停整个旧扩展后，这些附加入口也会暂停。

## 在其他酒馆安装

需要服务器管理权限和 `enableServerPlugins: true`。目标仅为上述已核验1.19.0；未来版本需重新验证。浏览器缺少Worker、Web Crypto或解压流时保留原生保存。

```bash
# 先预览，再安装；不会覆盖已有同名目录
python3 scripts/install.py --host /你的/SillyTavern
python3 scripts/install.py --host /你的/SillyTavern --apply
```

辅助生成适配仅针对当前用户自己安装的 4.12.2 构建。服务端在原文件的访问权限下核对宿主和助手文件指纹，匹配时才在该次浏览器响应内接入清酌；不会改助手磁盘文件。其他版本沿用助手原流程。

安装后重启对应酒馆实例。停用鸡尾酒、鸡尾酒+、柏宝箱和旧 `st-linear-parser`，保留业务插件。若鸡尾酒+注入了 Early Bridge，按其说明精确撤除；本安装器只管理自己的早期恢复块，不删除其他启动注入。清酌只注销同源精确 `/api/plugins/cocktail-plus/sw.js` 旧Service Worker，不清其他缓存、不自动刷新；受旧SW控制的页面需要全部关闭重开。

安装器管理自己的两个目录、`public/index.html` 的早期恢复脚本，以及经过完整文件哈希核验的设置、单聊、群聊、内置 Quick Reply 的读取与相关保存准备入口。早期脚本未加载时使用原生请求；业务插件的完整请求链仍保留。安装和回退保留标记之外的原有字节，以及原文件的属主、组和权限。

```text
public/scripts/extensions/third-party/tavern-flow/
plugins/tavern-flow/
```

ZIP中 `extension/`、`server-plugin/` 是安装副本，`client/`、`server/`、`shared/`、`tests/` 是同版源码。本项目包含前后端两个部分，请下载发行包或克隆仓库后运行上述安装器。不要把本仓库或 ZIP 网址直接填入酒馆的扩展安装框，否则无法完成配套服务端安装。

## 停用与回退

日常可在面板关掉相应模块。发生保存冲突或结果未确认时，先复制未保存输入与修改，再完整刷新重新读取；开关不会解除本页守卫。它保守地暂阻本页设置/单聊/群聊保存。

卸载自己的文件前先停止保存、关闭页面，执行：

```bash
python3 scripts/install.py --host /你的/SillyTavern --rollback
python3 scripts/install.py --host /你的/SillyTavern --rollback --apply
```

核对文件和启动块哈希后，只删除自身两个目录及精确匹配的启动块及原生读取标记；自有块或标记被后续改动则拒绝删除。安装或卸载异常时逐项补偿；若磁盘持续报错，保留恢复清单和原始文件并打印路径，需保持停服处理。重启酒馆，需要时恢复旧组合及其启动注入。设置命名空间可保留，不删除聊天。回退时保留安装前备份，避免用整份旧设置覆盖后续更改。

从 0.4.0、0.4.1 或 0.5.0 升级时，备份后停止酒馆，用新版安装器按上述步骤预览并回退旧标记，再安装 0.5.1 后重启。此过程保留原清酌选项。

## 验证和已知边界

```bash
npm test
npm run check
TAVERNFLOW_HOST_ROOT=/实际/SillyTavern npm test
```

第三条应指向未注入清酌的已核验原版源码副本。该检查仅读取源码，原生适配测试在临时 DATA_ROOT 写入，不载入正式设置。无 npm 运行依赖。资源少时添加 `UV_THREADPOOL_SIZE=1 NODE_OPTIONS=--v8-pool-size=1`。

报告只包含汇总与合成夹具，不包含私人卡片、聊天、预设或原始网络记录。历史版测量不与本版收益相加。

首次原生设置读取可在 Worker 启动前保留基线，同页停用和重新启用仍保留已记录的哈希。尚未在页面打开的目标可能先查询服务器状态。原生路径、第三方 XHR 或独立 Worker 的写入不经过这个队列；停用期间的原生写入可能使重新启用时报冲突，此时先保留修改再刷新。已发出的保存超过 90 秒仍未完成应答时，提示结果未确认，清酌不会重写。

尚未验收真机耗电/内存峰值，未优化移动键盘、图片代理或全聊天首次构造。Worker 最多保留 6 份完整快照，规范 JSON 总大小不超过 32 MiB；该限制不等于整页 JS 内存上限。正文模型测试不等于所有业务插件的全部辅助模型调用认证。
