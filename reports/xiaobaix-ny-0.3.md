# 小白X与 NY 循环任务：0.3 调查与迁移

正式已升级官方3.2.6并恢复当前NY六任务；配置页、启停持久化及一个主程序的真实指定模型执行均已完成。运行证据与覆盖边界见 [0.3主验收](acceptance-0.3.md)，下文保留调查时的静态与隔离来源。

## 结论

原安装的小白X是官方 3.2.5，并非仍有本地魔改。Git 工作区干净，提交 `707e03f2d7f75bb6588b29625b3bd61b6c4a7c5a` 与 GitHub 官方 `v3.2.5` 相同。原更新地址 Gitcode 镜像当前仍停在该版本，GitHub 官方已发布 3.2.6。

本轮固定官方 `v3.2.6`：`c508e5f5fc0b80332837868ad380675cce211e47`。隔离酒馆已替换，3481 个 Git 跟踪文件与官方提交逐字节核验一致，Git 工作区干净，没有修改上游源文件或构建产物。

NY 任务消失有明确的数据原因：当前选中的 NY 预设只有 `character_id: 100001` 的提示词顺序条目，未保存预设循环任务。官方小白X 3.2.5 与 3.2.6 都只读取：

```text
prompt_order 中 character_id 为 100000 的条目
  → xiaobai_ext.scheduledTasks
```

因此升级插件本身不会凭空恢复这些任务。目前没有证据证明此字段由清酌删除。

## 最小恢复范围

用户服务器已有 NY 1.4.2 与 1.4.3；二者的前 6 个任务完整定义相同，包含名称、脚本、配置及身份字段。恢复来源是这些已拥有的定义，不是猜写作者脚本。

恢复 6 个任务：NY-Sigon主程序、NY-Sigon、NY-Sogon主程序、NY-Sogon、NY-档案馆、NY-档案馆主程序。仅向当前 NY 1.4.5 增加必要的 100000 条目和任务字段，104 个提示词、100001 顺序、模型参数、正则与其他字段全部保留。1.4.3 与 1.4.5 的 104 个提示词标识完全相同，其中 101 个正文相同；这支持复用既有任务，但不能代替真实运行验收。

未恢复 1.4.3 额外携带的第 7 个旧适配器。该适配器会在 `SETTINGS_UPDATED` 上重新挂载并清理任务记录，还设置重复挂载和看门狗；前 6 个任务由官方 `XBTasks` 原生识别，不依赖它出现。旧预设原文保留，没有删除或修改。

- 迁移拒绝覆盖已有不同任务；回退保留随后发生的无关字段变更，遇到任务自身已被修改则拒绝覆盖。
- 主控的新浏览器已确认官方 `XBTasks.list('preset')` 返回 6 个任务。面板启停、配置页、真实模型变量写回与刷新回读仍以主验收记录为准。

## 原生运行边界

循环任务总开关、插件总开关及单任务启用状态都必须打开。预设任务仅在聊天补全 API 与当前 NY 预设下生效。

3 个主程序当前 `api.provider` 为 `st`。作者脚本在该分支不传独立模型和密钥，沿用酒馆当前模型；任务配置中历史模型占位字符串不会成为请求模型。测试应在隔离酒馆将当前模型限定为 `gemini-3.8-flash-high`，并保留网络守卫。配置面板中的独立 API 信息不得输出到报告。

`NY-Sigon`、`NY-Sogon`、`NY-档案馆` 是配置界面任务；相应“主程序”才会生成、解析标签并写变量。只打开配置页不能算主程序运行通过。主程序内置重试，模型请求次数和最终变量写入应分别统计。

## 审查门与剩余风险

结论为 `Local Fix Only`：升级到官方原版并恢复一个预设字段，不二开小白X、不增加新的适配器，不改提示词和作者任务正文。正式替换前须私有备份、停止本实例、原子更换该扩展目录、精确合并预设任务，重启后由全新浏览器确认官方版本、任务启停与持久化。

可逆脚本只恢复本次负责的目录或任务字段，不用整份旧设置覆盖用户的新编辑。真实模型输出、完整 NY 业务语义、官方 3.2.6 全部其他功能与手机真机体验不由上述检查一并认证。
